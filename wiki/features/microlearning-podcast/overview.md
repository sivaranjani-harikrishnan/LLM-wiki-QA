# Feature: Microlearning Podcast

**Summary**: Microlearning Podcast is a private, per-user audio podcast generated automatically from a Microlearning (Let's Learn) article. It is never visible to admins or managers.

**Sources**: `Microlearning - Sheet1.csv`

**Last updated**: 2026-05-25

---

## What it does

From within the Let's Learn module, a user can generate a private audio podcast based on their Microlearning article. The podcast inherits the content of the article and presents it in an audio format.

## Who uses it

- **All HeySales users**: Can generate their own private Microlearning Podcast
- **No admin visibility**: Neither the article nor the podcast is visible to any other user

## Key differences from regular Podcasts

| Aspect | Regular Podcast | Microlearning Podcast |
|---|---|---|
| Created by | Admin / Content Publisher | Any user (self) |
| Assigned to | Learners by admin | Not assignable — private |
| Visible to admin | Yes | No |
| Appears in admin reports | Yes | No |
| Source | Uploaded assets | Microlearning article |
| Appears in My Courses | Yes (if assigned) | No |
| Appears in Explore | Yes (if published) | No |

## Privacy

The Microlearning Podcast follows the same strict privacy rules as the Microlearning article:
- Visible only to the user who generated it
- No admin, manager, or other user can see or access it
- Does not appear in any HeySales reports or dashboards

## Lifecycle

- Generated from a Let's Learn article
- Deleted when the parent article is deleted
- Accessible within the Let's Learn module only
