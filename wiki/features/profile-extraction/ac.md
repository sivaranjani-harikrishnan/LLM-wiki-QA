# Acceptance Criteria: Profile Extraction

**Summary**: No formal AC document exists for profile extraction as a standalone feature. The test cases in the source CSV test simulation creation with profile extraction as a component. Key ACs are captured in [[simulation-call-recording]] (AC-SCR-08 through AC-SCR-14).

**Sources**: `raw/Profile extraction - Sheet1.csv`

**Last updated**: 2026-05-25

---

## Note on source document

`raw/Profile extraction - Sheet1.csv` contains test cases primarily focused on creating simulations using call recording upload and extraction. The extraction-specific ACs (file acceptance, extraction flow, error states, reuse, account scoping) are documented in [[simulation-call-recording]] under AC-SCR-08 through AC-SCR-14, as they share the same source material and functionality.

The Profile extraction CSV also includes general simulation creation test cases (TC0001 — TC0002) that are covered in the simulations feature test coverage.
