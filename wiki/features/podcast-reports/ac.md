# Acceptance Criteria: Podcast Reports

**Summary**: Defines the analytics metrics available for podcasts and which are currently implemented vs deferred.

**Sources**: `raw/02c3a872-921e-496b-be61-05f09c340c43_Podcast_Analytics.pdf`

**Last updated**: 2026-05-25

---

## AC-PR-01: Completion Rate metric

GIVEN a podcast has been published and listened to by learners
WHEN a manager views podcast analytics
THEN a Completion Rate metric is shown (percentage of listeners who completed the podcast)

(source: 02c3a872-921e-496b-be61-05f09c340c43_Podcast_Analytics.pdf)

## AC-PR-02: Total Time Spent metric

GIVEN a podcast has been listened to
WHEN a manager views podcast analytics
THEN Total Time Spent across all listeners is displayed

(source: 02c3a872-921e-496b-be61-05f09c340c43_Podcast_Analytics.pdf)

## AC-PR-03: Average Time Spent metric

GIVEN a podcast has been listened to by multiple learners
WHEN a manager views podcast analytics
THEN Average Time Spent per listener is displayed

(source: 02c3a872-921e-496b-be61-05f09c340c43_Podcast_Analytics.pdf)

## AC-PR-04: Listen time graph — deferred

GIVEN podcast analytics are displayed
WHEN a listen time graph over a time period is considered
THEN this graph is deferred by engineering and is not part of the current implementation

(source: 02c3a872-921e-496b-be61-05f09c340c43_Podcast_Analytics.pdf)
